# Отчет по практической работе: Развертывание API на Flask + PostgreSQL через Docker

**Проект:** Микросервис трекинга визитов
**Стек:** Python 3.12, Flask, PostgreSQL 16, psycopg2, Gunicorn, Docker, Docker Compose.
**Окружение:** Контейнеризированное приложение (порты: 8089 -> 5000).

## Цель работы

Воссоздать и запустить микросервисное приложение, состоящее из веб-API на базе Flask и базы данных PostgreSQL. Настроить их взаимодействие внутри Docker-сети с использованием `docker-compose.yml` и переменных окружения, а также проверить работоспособность всех REST-эндпоинтов.

## Структура проекта

Проект успешно сконфигурирован с использованием следующих компонентов:
* `app.py` — основной код веб-сервера на Flask с тремя маршрутами (`/`, `/visits`, `/health`). Реализован механизм повторных попыток подключения к БД (retry-логика) на случай, если СУБД стартует дольше веб-сервера.
* `init.sql` — скрипт инициализации, автоматически создающий таблицу `visits` и добавляющий первичную запись при первом запуске базы данных.
* `Dockerfile` — инструкции для сборки легковесного образа на базе `python:3.12-slim` с установкой системных зависимостей, созданием отдельного пользователя `appuser` и запуском через WSGI-сервер `gunicorn`.
* `docker-compose.yml` — оркестрация двух сервисов (`web` и `db`) с настройкой Healthcheck, пробросом портов и монтированием томов (volumes) для сохранения данных при перезапуске.
* `.env` — файл конфигурации с секретами и параметрами подключения.

## Результаты тестирования API

После успешной сборки и запуска контейнеров (`docker compose up -d --build`) были протестированы все доступные эндпоинты. Ниже представлены фактические ответы сервера, подтверждающие корректную работу приложения и связи с БД.

### 1. Главная страница (Фиксация визита)
**GET** `http://localhost:8089/`

Сервер успешно подключается к PostgreSQL, добавляет новую запись о визите в таблицу `visits` и возвращает информацию об окружении.

**Ответ сервера (JSON):**
```json
{
  "env": "production",
  "hostname": "0906743e231a",
  "message": "Hello from Docker + Postgres!",
  "total_visits": 2,
  "visit_id": 2
}
```

### 2. История визитов
**GET** `http://localhost:8089/visits`

Выборка последних 20 записей из базы данных. В ответе присутствует как ручная вставка из `init.sql` (`/init`), так и зафиксированный визит с главной страницы.

**Ответ сервера (JSON):**
```json
[
  {
    "created_at": "Wed, 28 Oct 2026 22:04:40 GMT",
    "id": 2,
    "path": "/"
  },
  {
    "created_at": "Wed, 28 Oct 2026 22:00:00 GMT",
    "id": 1,
    "path": "/init"
  }
]
```

### 3. Проверка состояния (Healthcheck)
**GET** `http://localhost:8089/health`

Эндпоинт, который используется Docker'ом для проверки жизнеспособности контейнера. Подтверждает, что соединение с базой данных активно.

**Ответ сервера (JSON):**
```json
{
  "db": "connected",
  "status": "ok"
}
```
